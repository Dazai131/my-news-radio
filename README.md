# ニュースラジオ

AI・3D制作・PC・ゲームのニュースを、キャラクターと日本語音声でお届けします。

- 公開先： https://dazai131.github.io/my-news-radio/
- 1回5〜10分。毎朝8時（日本時間）から作成・更新を開始します。
- 黄色い再生ボタンで再生し、左の番号でニュースを切り替えられます。
- 各ニュースの出典と台本はページ内で確認できます。

音声：**COEIROINK:リリンちゃん（のーまる）**  
キャラクター画像：AI生成
